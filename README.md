# 🔐 CHK Tropa do Bom e Novo

Sistema completo de validação de cartões 3DS com API real integrada.

## 🔥 VALIDAÇÃO REAL!

Este sistema usa a **API REAL** da Cakto/Cielo para validação 3DS autêntica!

### ✅ Componentes:
- **validador_5.py** - Validador 3DS real (Cakto/Cielo)
- **api_backend.py** - API Flask (backend)
- **index.html** - Interface web moderna
- **main.py** - Lógica de processamento

---

## 🚀 Instalação Rápida (Windows)

```batch
1. Clique em: INICIAR_CHK_COMPLETO.bat
2. PRONTO! ✅
```

**O script vai:**
- ✅ Instalar dependências
- ✅ Iniciar a API
- ✅ Abrir o navegador
- ✅ Funcionar 100%!

---

## 🔧 Instalação Manual

### 1. Instalar Dependências:
```bash
pip install -r requirements.txt
```

### 2. Iniciar API:
```bash
python api_backend.py
```

### 3. Abrir Interface:
- Clique em `index.html`
- OU acesse: `http://localhost:5000`

## 📱 Usar no Celular

### No PC:
