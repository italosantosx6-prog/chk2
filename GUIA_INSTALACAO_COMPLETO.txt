════════════════════════════════════════════════════════════════════
    ⚠️ SOLUÇÃO DE PROBLEMAS
════════════════════════════════════════════════════════════════════

PROBLEMA: "Python não encontrado"
SOLUÇÃO: 
- Instale Python: https://www.python.org/downloads/
- Marque "Add Python to PATH"
- Reinicie o PC

PROBLEMA: "pip install falha"
SOLUÇÃO:
- Execute: python -m pip install --upgrade pip
- Tente novamente

PROBLEMA: "API offline no navegador"
SOLUÇÃO:
- Verifique se api_backend.py está rodando
- Veja se apareceu erro no terminal da API
- Tente: python api_backend.py

PROBLEMA: "Não acessa do celular"
SOLUÇÃO:
- PC e celular na MESMA rede Wi-Fi
- Use o IP correto que apareceu na API
- Desative firewall temporariamente

PROBLEMA: "Validação muito lenta"
SOLUÇÃO:
- É normal! A API real da Cakto demora
- Cada cartão leva 5-20 segundos
- Tenha paciência

PROBLEMA: "Muitos erros HTTP 429"
SOLUÇÃO:
- A API está bloqueando por limite de requisições
- Aguarde 1-2 minutos
- Tente novamente com menos cartões
